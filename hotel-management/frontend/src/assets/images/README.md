```
├── banner/
│   └── trang-tri-phong-khach-san-5.jpg    (Ảnh banner chính)
├── room/

│   ├── anh-phong-2.jpg                    (Ảnh phòng Superior)

    ├── restaurant.jpg                     (Ảnh nhà hàng)

```

## Cách Thay Thế Ảnh

Nếu muốn thay thế ảnh, chỉ cần:
1. Xóa ảnh cũ
2. Thêm ảnh mới với **tên file chính xác**
3. Làm mới trang (Ctrl+F5)

## Lưu Ý

- Tên file phải khớp chính xác (phân biệt chữ hoa/thường)
- Nếu ảnh không tìm thấy, sẽ hiển thị placeholder
- Kích thước ảnh nên < 500KB để tải nhanh
